We're thrilled to announce that nvisy is now available in private beta. This marks a major milestone in our journey to make document processing intelligent, secure, and effortless.

## Features

- nvisy Server with AI-powered field detection and data extraction
- nvisy Studio desktop app for document review and annotation
- REST API for seamless integration with your workflows
- Web application for managing documents and teams
- Workspace management with granular permissions

## Improvements

- 95% field detection accuracy on standard business documents
- Under 3 second processing time for single-page documents
- Better OCR for handwritten text and complex layouts
- Interactive onboarding with sample documents
- Comprehensive audit logging for compliance
