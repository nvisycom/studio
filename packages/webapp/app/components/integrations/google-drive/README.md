# Google Drive Components

This folder contains all components related to the Google Drive integration.

## Structure

- `ConnectGoogleDriveDialog.vue` - Dialog for connecting to Google Drive
- `ConfigureGoogleDriveDialog.vue` - Dialog for configuring Google Drive
  settings
- `GoogleDriveSettings.vue` - Settings panel for Google Drive
- Other Google Drive-specific components

## Usage

Components in this folder should be imported from the main integrations barrel
export:

```typescript
import { ConnectGoogleDriveDialog } from "@/components/integrations";
```
