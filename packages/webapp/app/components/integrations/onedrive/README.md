# OneDrive Components

This folder contains all components related to the OneDrive integration.

## Structure

- `ConnectOneDriveDialog.vue` - Dialog for connecting to OneDrive
- `ConfigureOneDriveDialog.vue` - Dialog for configuring OneDrive settings
- `OneDriveSettings.vue` - Settings panel for OneDrive
- Other OneDrive-specific components

## Usage

Components in this folder should be imported from the main integrations barrel export:

```typescript
import { ConnectOneDriveDialog } from '@/components/integrations'
```
